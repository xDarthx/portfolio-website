# Jacob Grant's Portfolio Website

Welcome to my personal **"resume" website**. This project serves as a centralized hub to showcase my professional background, technical skills, and software development projects.

**Live Demo:** [https://xdarthx.github.io/portfolio-website/](https://xdarthx.github.io/portfolio-website/)

---

## 📖 About The Project

This website is a **Single Page Application (SPA)** designed to provide a comprehensive overview of my work and experience. It is built to be responsive, fast, and user-friendly.

On this website, you will navigate through three main sections:
* **Home Page:** A summary of who I am and my professional focus.
* **Projects Page:** A showcase of all the projects I have worked on, demonstrating my coding abilities and problem-solving skills.
* **About Me Page:** A deeper look into my background, interests, and journey as a developer.

---

## 🛠️ Technologies Used

This project leverages modern web development tools to ensure performance and maintainability:

* **React** - Used as the base framework for building the user interface.
* **JavaScript (ES6+)** - Logic and interactivity.
* **CSS3** - Styling and responsive design.
* **GitHub Pages** - Hosting and deployment.
